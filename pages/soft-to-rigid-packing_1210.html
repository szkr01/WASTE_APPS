Method note

探索本体は Nakajima (2026) の公開 2D simulator の考え方をブラウザ用 Web Worker に組み直したもの。energy は pair overlap² + wall violation² + μL、momentum gradient で更新する。

最終値は rigid square の中心を一様に外へ拡大し、SAT で pair overlap が消える最小倍率を二分探索してから tight bounding square を測る。

これは最適性証明ではない。ブラウザ探索の結果であり、既知最良値を保証しない。
